Short-lived tokens.
RTC, Signaling, at Chat user tokens gamit ang official Agora token builder. App Certificate ay nasa server lang. Hindi patunay ng enabled service ang successful token generation.
Kailangan ang App ID at App Certificate sa .env. Hindi sine-save ang token sa disk o browser storage.

      
YOUR EVENT RUNBOOK
Configuration, hindi rewrite.
  1. Bago umalis
    Dalhin ang event-kit folder at Node.js 24+. Kasama ang built UI, contracts, at runtime dependencies. Walang keys sa package.
  2. Pagkabigay ng credentials
    Kopyahin ang .env.example bilang .env. Ilagay ang App ID, App Certificate, at REST Customer ID/Secret kung ibinigay. Magkaiba ang mga ito; hindi lahat ng products ay enabled sa iisang key.
  3. I-enable ang napiling services
    Itakda ang AGORA_LIVE_ENABLED=true, saka npm start. Para sa Chat, Whiteboard, o Classroom, ilagay rin ang product-specific configuration.
  4. Read-only test muna
    Subukan ang channel list o agent list. Ang 401/403 ay credential o permission issue; ang empty list ay hindi patunay na gumagana ang media.
  5. Feature test at cleanup
    Para sa voice/video, dalawang clients. Para sa AI, transcription, recording, at streaming, i-start → i-query → i-stop ang task. Itala ang task IDs at huwag iwanang running.
Native SDKs, hardware, partner callbacks, at specialized auth ay may hiwalay na setup. Ang catalog ay coverage map, hindi pangakong lahat ng Agora products ay enabled sa event account.
